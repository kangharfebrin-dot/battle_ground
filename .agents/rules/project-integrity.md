# Project Integrity Rules

- Baca AGENTS.md, PRD.md dan docs terkait sebelum perubahan besar.
- Audit struktur dan pola yang ada sebelum menambah framework, package atau layer.
- Pertahankan perubahan pengguna dan jangan menimpa file tanpa membandingkan isinya.
- Jangan mengarang endpoint, table, dependency, screen, fitur, command atau hasil test.
- Catat hal yang belum diketahui sebagai TBD.
- Jangan reset/drop/truncate database, commit, push, deploy atau ubah secret tanpa izin jelas.
- Uji perubahan relevan dan laporkan command beserta hasil aktual.
- Perbarui dokumen ketika keputusan atau behavior terdokumentasi berubah.
